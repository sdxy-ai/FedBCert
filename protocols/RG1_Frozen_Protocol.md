## 1. 研究问题与预先承诺

在固定真实图及联邦诱导子图上，同时测量：参数匹配的图传播能否相对无图控制提供效用；隐藏关系是否改变同一冻结模型的类别；不同认证规则能认证多少节点；认证后精确回退能否保持指定完整图类别，并以多少 CPU 代价换取多少应用层消息。

成功标准是按冻结的公平协议完成全矩阵、完整保存可复现证据并诚实报告结果，**不是必须显著、必须正收益或同时满足某个有利阈值**。P 不优于 I/MLP、几乎无结构敏感性、覆盖率低、载荷增加或 CPU 更慢，均为有效负面结论，不触发更换数据集/种子/条件。

Cora、CiteSeer 已在既有研究中使用：这是已有基准上的新增联合分析，不是未见数据的独立外部验证。新的随机重复不等于新抽样的独立真实图。

## 2. 范围、数据版本与实验单元

固定两个数据集，不根据本轮任何新效用或敏感性结果替换：

## 3. 种子、划分与隔离

预定工程种子：42020000，仅用于无效用输出的玩具接口/资源预检，不进入科学估计。正式种子固定为 **42020101–42020108**。本轮在 configs、scripts 和当前研究目录的文本中未找到该种子空间，但未穷尽全部二进制工件，不能声称已证明全球未使用；运行前须将用途和查重范围写入清单。

固定派生方法：`SeedSequence([base_seed, dataset_id, stream_id, ...])`，dataset_id 为 Cora=1、CiteSeer=2；stream_id 为 split=11、METIS=12、random partition=13、model=14、小批抽样=15。P/I 逐轮/客户端训练流由同一 model seed、round、client_id 派生。数据集间不共享原始随机流；同一数据集、同一 base_seed 的两个分区共享全局标签划分和模型初始化种子。

- 按全局类别分层划分 30% 训练、10% 保留未用审计、20% 验证、40% 测试；复用 `stratified_four_way_masks` 的计数分配与逐类随机排列，函数及依赖版本需冻结，掩码互斥并覆盖所有节点。比例经离散分配后以实际计数为准，不强行写成每图 2,400 个测试节点。
- METIS 与均衡随机成员关系只读取拓扑/节点数及各自种子，复用 `fedbeso/operator.py:58–88` 的语义；固定 pymetis 版本及排序后的邻接。空客户端或客户端无训练节点为配置失败，不重抽有利种子。
- 同一配对单元的 P/I/MLP 使用完全相同的图、特征、成员关系、训练/验证/测试掩码。
- 模型训练只读取本地诱导图、训练标签；选轮只读取本地验证标签。测试和未用审计标签在训练客户端中屏蔽；直推设置允许无标签节点特征参与传播，但不允许完整图传播/认证/测试结果参与检查点或配置选择。
- 所有 96 个模型的选定检查点、验证轨迹及输入哈希固定后，才统一开启测试评估。不得边看测试边换工作点。完整图参照只在此后用于诊断和离线一致性核查，不进入路由决策或回退缓存。

## 4. 模型、容量与固定训练预算

| 模型 | 固定定义 | 结构作用 |
|---|---|---|
| P | stock `dual_feature_spectral`，hidden=64，feature depth=2，K=3，alpha=0.25 | 训练/局部推理用各客户端诱导 P，完整图参照用指定完整图 P* |
| I | 与 P 完全相同架构、参数维数、初始 state_dict、随机流和预算 | 所有训练、局部及“完整”推理中都用 I，绝不在测试时换回 P* |
| 强纯特征 MLP | stock `feature_only_mlp`，两层残差 GELU+LayerNorm，宽度按参数计数固定 | 不读取图或计数；不是同一个双分支模型事后设 alpha=0 |

P/I 使用 CE(feature)+CE(spectral)，MLP 使用 CE(output)。相同的是优化器、轮数、本地 epoch、数据及匹配容量，**不宣称三模型训练目标完全相同**。采用 Adam，学习率 0.01、weight decay 5e−4、dropout 0.2、残差系数 0.5；各客户端各轮重置优化器；按有标签训练节点数加权 FedAvg；全客户端参加。theta 初始化 (0.5,0.5,0)，允许学习负值，不用认证代理损失。

每个模型独立选择 pooled validation Macro-F1 最大的轮次，完全平局取最早轮；不按认证覆盖率、完整图表现或测试指标选轮。训练 float32；选定权重转 CPU float64 后进行冻结评估，P 的归一化权重须在 float64 重建而非只转换 float32 稀疏值。训练/计时设备在执行前清单冻结，不因某方法较慢换设备。

容量规则（由 C 的模型构造静态推得，尚待实例化核验）：输入维 d、类别 C、宽度 h、K=3 时，P/I 参数数为 (2dh+h^2+(5+2C)h+2C+3)；MLP 为 (w^2+(d+C+4)w+C)。选择最接近 P 参数数的正整数 w，绝对差平局取较大宽度，不按效用调宽度。

| 数据集 | P/I 参数 | MLP 宽度 | MLP 参数 | 相对差 |
|---|---:|---:|---:|---:|
| Cora | 188,753 | 121 | 189,372 | 约 +0.328% |
| CiteSeer | 479,183 | 125 | 479,756 | 约 +0.120% |

这些是给定架构和维数下的算术预期，不是本轮模型运行结果。若实例化计数不符，停止查明版本，不通过试验效用另选更强控制。I/MLP 在固定平局规则下按定义图不变，覆盖率 1 是对照性质，不记为 FedBCert 新认证收益。

## 5. 冻结诊断与三种认证规则

仅在同一个 P 检查点、同一局部 logits、同一 count-bound vector 上比较：

1. 原始球对称：保留质量递推，逐竞争类权重差范数；式（19），不是 classwise-sum 消融。
2. 非负域强对称：同一半径除 √2，利用非负单位球直径；不将旧表原对称结果改名充当此基线。
3. 非负区间：式（24）—（30）按类差方向和 theta 符号选端点；不把 combined 并集当作第四项独立改进。

使用指定完整图的精确跨 owner 邻居计数作为外部服务生成的有效上界，数学语义始终 0≤c≤b，不用等式约束缩小补全集。认证器本身只读取局部图/特征和所有本地节点的上界，不读取远端端点/特征。该计数来源是实验接口假设，不代表真实机构的计数真实性已经解决。

固定 CPU float64、eval/no-grad；数值接受 guard=1e−6，必须每个竞争类的充分下界严格超过 guard。原始算法的精确算术保证与该浮点接受分开报告；禁止称为严格浮点证明。拟复用 `geometry_baselines.py` 的受限语义，执行入口须先解决/隔离审计 B1、B2 并审核；本轮不实现。

每个单元保存局部和指定完整图的类别、logits、softmax：报告类别不一致率、最大类别概率差≥0.05 的比例，以及完整的逐节点差异，不只报告敏感节点。指定完整图是一张合法补全，不是对所有补全的穷举。

所有节点与暴露节点均报告；K=3 时暴露集为边界节点及其一跳本地邻居，仅由拓扑/计数决定。各模型共享该分组，空组报告 NA。保存各阶表示偏差、类别下界诊断、所有方法接受掩码及最小间隔。报告总覆盖率、暴露覆盖率、认证准确率（分母为相应全部目标）、已认证节点在指定补全上的翻类数；没有精确鲁棒事件 oracle，因此真实图认证 recall/precision 是 NOT APPLICABLE。

## 6. 推理策略、消息计费、缓存与批处理

P 模型执行以下六种服务策略，固定顺序后循环轮转：

| 策略 | 本地预测/摘要 | 远端计算 | 类别要求 |
|---|---|---|---|
| L：仅本地推理 | 本地模型，无远端摘要 | 无 | 可以不同于完整图，必须如实计差异，不因此中止 |
| F：全部目标精确完整图推理 | 不预先本地推理，不收费无用摘要 | 全部目标共同依赖的精确聚合 | 必须与离线完整图参照类别一致 |
| E：仅结构暴露筛选+回退 | 本地预测+bit-packed 边界存在性 | 对暴露目标精确回退 | 必须类别一致；保留为第 4.8 节对照 |
| S：原对称+回退 | 本地预测+有效逐节点计数 | 对未认证/不可用目标回退 | 必须类别一致 |
| D：强对称+回退 | 同 S | 同一回退引擎 | 必须类别一致 |
| N：非负区间+回退 | 同 S | 同一回退引擎 | 必须类别一致 |

I/MLP 另行测同一目标上的本地/结构不变完整参照、CPU 和效用，载荷为零；不强迫它们调用没有数学必要的远端服务来抬高对照成本。主应用比较固定为同一 P 模型上的 N 对 F、D、E；不能用不同模型替换该配对。

主负载：该单元**全部冻结测试节点，一次共同批处理**。次负载：用 stream 15 从同一测试节点无放回抽取 32 个并排序；跨策略和模型相同，抽样不看标签/预测/认证。主次结果分别报告，不把小批高收益替换主批结论。

以下逐项继承第 4.8 节 / E.2 及原 on-demand JSON 的会计语义：

- 每次计时创建新服务及空消息状态，不跨批/跨策略复用传播结果。warm-up 后正式重复仍从空状态开始。批内按源节点、接收 owner、传播阶去重，所有策略共用 codec、依赖规划及精确引擎。
- 回退展开至 K−1 阶，包括 remote–remote 依赖；各 owner 使用完整度数和自环。已认证节点仍可能作为其他目标的依赖，不能从覆盖率直接推导字节减幅。
- 可以复用本次该策略实际计算且已计时的本地编码与图不变特征 logits；禁止免费预计算完整图隐藏状态/logits。中心化参照仅在计时外独立核查，不进入缓存。
- 总载荷＝摘要请求/响应＋聚合请求/响应的实际序列化字节；包括快照/协议/owner/阶数消息头、节点 ID、float64 向量。计数用 uint32，边界存在性 bit-pack；检测越界，不截断溢出。必须解码后使用，而非只估算理论消息数。
- F 不预先运行本地推理或获取不需要的 count bounds；E 仅获取存在性；S/D/N 获取涉及目标 owner 的全部本地节点有效计数，不能只付目标节点的计数费。
- L 不实例化它不需要的远端服务、无摘要/聚合消息。计其必要的本地图/索引构建及本地前向；单列 CPU，不将 L 的零字节称为保持完整图类别的方案。
- 公平计时边界：必要服务/本地视图构建与快照核验、本地前向、摘要产生与解码、证书、依赖规划、序列化/解码和回退均计入；磁盘加载和离线中心参照核查不计。任何为关闭 B2 新增的必要完整性开销都要进入计时并逐策略披露，不免费移到计时外。
- 记录摘要字节、聚合请求/响应字节、总字节、应用消息条数、远端向量数、实际传播行数、直接本地输出/回退比例，以及总 CPU 与各阶段时间。消息条数不是网络包数。
- 不含 TCP/TLS、跨机调度、访问审批、人工作业或真实网络延迟；不报告这些成本已下降。CPU 回放时间不是分布式系统端到端时延。

计时固定单进程 CPU float64，intra-op/inter-op 均 1 线程，1 次预热、3 次正式重复。主 CPU 列沿用原 runner 的 `perf_counter` 单线程 CPU 回放墙钟时间；同时记录 `process_time` 作为辅助项，不用它替换主列或宣称分布式时延。P 的六策略按 case index+workload index+repetition index 循环轮转。32×2×6×3＝**1,152 条 P 正式服务记录**；I/MLP 各自本地控制另有 32×2×2×3＝384 条，单独统计，不混作 P 的独立重复。

## 7. 指标、统计与完整报告

效用以每单元合并客户端测试节点的 Macro-F1/准确率为主，另报最差客户端 F1（统一类别集合，zero_division=0）、暴露组 F1；保存 P−I、P−MLP 配对差，不从双分支对 MLP 的优势单独推断图传播因果贡献。

每个正式 seed 内先对 3 次 CPU 重复取中位数，再算 N/F、N/D 等逐 seed 时间比；载荷减幅为逐 seed 的 (1-B_N/B_F) 等，不能用汇总均值之比替代。字节对正式重复应完全一致，否则停止。F 字节为零时比率记 NA，并报告零字节单元数与绝对差，不偷偷删除样本或加平滑常数。

固定统计方案：

- 先分别展示每个 dataset×partition 的八个配对重复，再等权汇总两个分区；最后两数据集等权汇总。跨单元均值不按节点数加权，不把测试节点/客户端/计时重复当独立样本。
- 配对百分位 bootstrap 10,000 次，分析 RNG=42028616。同一数据集每次重采样八个 base_seed 索引，该索引同时作用于两个分区和全部模型/策略/指标，以保留配对相关；两个数据集各自重采样。报告描述性 95% 区间及逐 seed 表。
- 区间仅刻画这些固定真实图上的划分/训练随机性，不代表独立图总体。没有以显著性为门槛的假设筛选，不增加事后 p 值或因果/总体推广声明；多指标区间不是同时覆盖保证。
- 固定报告三组效应：P−I/P−MLP 效用；N 相对原/强对称的覆盖差；N 相对 F/D/E 的载荷与 CPU 配对变化。无论正负均报告，主批与小批均报告，不按结果选图或只展示优势分区。

## 8. 完整性与明确停止条件

执行前门：作者批准、B1/B2 关闭或经过批准的严格隔离通过、新入口白名单及快照回归通过、数据版本/输入 hash/参数数目核验、软件硬件与全部配置清单冻结。以上未完成不得开训练。

硬停止并保留失败记录，不得容差豁免或静默重试：

1. 任何已认证节点在指定完整图上的类别变化；F/E/S/D/N 任意最终类别不同于中心参照。**L 的预期类别差异不属于该停止项。**
2. 回退目标 logits 相对中心参照最大绝对误差超过 1e−10；类别比较采用相同首索引平局规则、零翻类容差。仅比较回退 logits，不要求已认证节点返回本地 logits 等于完整图 logits。
3. 非有限值、负隐藏表示、非法行随机/自环/边权/上界条件、解析下界或表示误差诊断超出预定 1e−10 容差，或三规则接受集合违反理论预期层级。诊断容差不构成严格舍入证明；边界附近问题保留调查，不调 guard 追求通过。
4. 模型/输入/软件指纹变动、缓存污染、类别/节点顺序错配、计费漏项、重复字节不一致、标签隔离失败、矩阵缺失/重复或资源越限。
5. 数据缺失或输入版本/参数数量不符。若客户端训练掩码为空，报告失败，不换种子重造。
